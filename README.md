# BOOKLY - E-book Service Website

🔗 **[Live Demo](https://minhphuc0227.github.io/E-book-Service-Landing-Page/)**

## Giới thiệu

BOOKLY là website giới thiệu dịch vụ đọc ebook trực tuyến, được thiết kế nhằm
cung cấp trải nghiệm sử dụng thuận tiện trên nhiều thiết bị và giới thiệu các
gói thành viên phù hợp với nhu cầu đọc sách.

Website tập trung trình bày dịch vụ, tính năng, gói thành viên, đánh giá người
dùng, câu hỏi thường gặp và thông tin liên hệ thông qua giao diện hiện đại,
rõ ràng và responsive.

## Mục tiêu dự án

Thiết kế và phát triển website thân thiện với người dùng, giúp truyền tải rõ
ràng các dịch vụ ebook và gói thành viên, đồng thời duy trì trải nghiệm nhất
quán trên desktop, tablet và mobile.

## Đóng góp

- Thiết kế cấu trúc website và giao diện dựa trên yêu cầu dịch vụ và hành trình người dùng.
- Phát triển giao diện responsive cho desktop, tablet và mobile bằng HTML5 và Tailwind CSS v4.
- Xây dựng các thành phần giao diện như navigation, tính năng, gói thành viên, FAQ, đánh giá và các khu vực kêu gọi hành động.
- Xây dựng hệ thống giao diện với màu sắc thương hiệu, typography, spacing, button, card và hỗ trợ chế độ sáng/tối.
- Áp dụng semantic HTML và các nguyên tắc accessibility để cải thiện khả năng sử dụng và cấu trúc trang.

## Tính năng chính

- Responsive trên desktop, tablet và mobile
- Giới thiệu dịch vụ ebook
- Trình bày các gói thành viên
- FAQ với accordion tương tác
- Hiển thị đánh giá người dùng
- Responsive navigation và call-to-action
- Hỗ trợ dark mode
- Semantic HTML và accessibility

## Công nghệ sử dụng

- HTML5
- Tailwind CSS v4
- JavaScript
- Figma
- Git & GitHub

## Kết quả

Hoàn thiện website dịch vụ ebook responsive với giao diện hiện đại, giúp trình
bày rõ ràng các dịch vụ, tính năng và gói thành viên trên nhiều kích thước
màn hình.

Dự án thể hiện kinh nghiệm trong responsive web design, UI development,
component-based styling và thiết kế giao diện hướng đến người dùng.

# English Version

## Overview

BOOKLY is an e-book service website designed to provide a convenient online
reading experience across different devices and present flexible membership
plans.

The website focuses on presenting BOOKLY's services, features, membership
packages, user feedback, frequently asked questions, and contact information
through a clean, modern, and responsive interface.

## Project Objective

To design and develop a user-friendly website that clearly presents e-book
services and membership options while providing a consistent experience across
desktop, tablet, and mobile devices.

## My Contributions

- Designed the website structure and user interface based on service
  requirements and user journeys.
- Developed responsive layouts for desktop, tablet, and mobile devices using
  HTML5 and Tailwind CSS v4.
- Implemented UI components including navigation, feature sections,
  membership plans, FAQ, testimonials, and call-to-action sections.
- Applied a customized design system including brand colors, typography,
  spacing, buttons, cards, and light/dark mode support.
- Applied semantic HTML and accessibility practices to improve usability and
  page structure.

## Key Features

- Responsive design for desktop, tablet, and mobile devices
- E-book service introduction
- Membership pricing and subscription plans
- Interactive FAQ accordion
- Customer testimonials
- Responsive navigation and call-to-action sections
- Dark mode support
- Semantic HTML and accessibility

## Technologies

- HTML5
- Tailwind CSS v4
- JavaScript
- Figma
- Git & GitHub

## Outcome

Developed a responsive and modern e-book service website that clearly presents
services, features, and membership plans across different screen sizes.

The project demonstrates experience in responsive web design, UI development,
component-based styling, and user-oriented interface design.
