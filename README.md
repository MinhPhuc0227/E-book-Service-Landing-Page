# BOOKLY - E-book Service Website

## Overview

BOOKLY is a responsive e-book service website designed to provide users with
a convenient online reading experience and flexible membership plans.

The website focuses on presenting BOOKLY's services, features, membership
packages, user feedback, frequently asked questions, and contact information
through a clean and modern interface.

## Project Objective

To design and develop a user-friendly website that clearly presents
e-book services and membership options while providing a consistent
experience across different screen sizes.

## My Contributions

- Designed the website structure and user interface based on the service
  requirements and user journey.
- Developed responsive layouts for desktop, tablet, and mobile devices
  using HTML5 and Tailwind CSS v4.
- Implemented reusable UI components, navigation, membership sections,
  FAQ interactions, testimonials, and call-to-action elements.
- Applied a customized design system including brand colors, typography,
  spacing, buttons, cards, and light/dark mode support.
- Used semantic HTML and accessible interface practices to improve
  usability and structure.

## Key Features

- Responsive design for desktop, tablet, and mobile devices
- E-book service introduction and feature showcase
- Membership pricing and subscription plans
- FAQ section with interactive accordion
- Customer testimonials
- Responsive navigation and call-to-action sections
- Dark mode support
- Semantic and accessible HTML structure

## Technologies

Developed a responsive and modern e-book service website that provides a
